# Project memory

## Product intent & audience

- Project: **UniAlDía** — appears to be a Spanish-language university/student-oriented web app or portal.
- Audience: Spanish-speaking users (likely students or university community).
- Production-quality, fully-featured web pages expected.

## Brand personality & voice

- Spanish-language UI and communication.
- Friendly, approachable, modern brand tone (inferred from name "UniAlDía" — "university up-to-date").

## Visual design & UX direction

- **Logo treatment**: Wordmark split into "Uni" + "AlDía" with distinct colors per segment.
  - Header logo: "Uni" in blue, "AlDía" in coral.
  - Footer logo (on dark navy/blue background): "Uni" in **white**, "AlDía" in coral (blue "Uni" was invisible on dark background).
- Footer background: dark navy/marino blue.
- Accent color: coral (used in logo and likely elsewhere).
- Tech: Vite + React + JSX, Tailwind CSS, Lucide React icons.
- Imports use `@/` path alias (maps to `src/`).

## Decisions, constraints & rationale

- Logo has two visual variants depending on background context (dark vs light) to maintain legibility.
- Header and footer logos are styled independently rather than sharing one fixed color set.
- Change scope was limited to footer logo "Uni" color; header logo intentionally left unchanged.
